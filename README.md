MediAssist AI 🏥

An AI-powered healthcare platform built using pure HTML, CSS, and JavaScript.
MediAssist AI provides symptom triage, appointment booking, doctor dashboards, medical records management, and multilingual healthcare assistance in a modern responsive interface.
