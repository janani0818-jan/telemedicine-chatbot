 ✨ Overview

MediAssist AI is a modern telemedicine platform prototype designed to streamline healthcare interactions through AI-assisted symptom analysis, appointment scheduling, doctor dashboards, and multilingual support.

The platform simulates a complete healthcare ecosystem with dedicated interfaces for:

- 👤 Patients
- 👨‍⚕️ Doctors
- 🛠 Administrators

Built entirely using vanilla frontend technologies without external frameworks.


🚀 Features

👤 Patient Portal

- 🤖 AI symptom assessment chatbot
- 📅 Appointment booking system
- 💊 Prescription management
- 📋 Medical records dashboard

 👨‍⚕️ Doctor Portal

 🛠 Admin Dashboard
